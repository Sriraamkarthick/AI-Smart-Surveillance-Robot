# 🤖 AI-Powered Smart Surveillance Robot

> An AI-powered autonomous surveillance robot with real-time object detection, ESP32-CAM live video streaming, MQTT-based remote control, and a responsive web dashboard accessible from both desktop and mobile devices.

---

## 📌 Project Overview

The AI-Powered Smart Surveillance Robot is an intelligent robotic system designed for real-time remote monitoring and surveillance. The robot streams live video using an ESP32-CAM module while performing AI-based object detection using the YOLOv8 model.

A responsive web application allows users to control the robot from any modern desktop or mobile browser without installing additional software.

---

## ✨ Features

- 🎥 Live video streaming using ESP32-CAM
- 🤖 Real-time object detection using YOLOv8
- 📱 Responsive web dashboard
- 🖥️ Desktop and Mobile browser support
- 🚗 Robot movement control
- 💡 LED control
- 📸 Image capture
- 📊 Detection logging
- 📡 MQTT communication
- 🌐 Wi-Fi controlled robot
